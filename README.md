# GitHub Profile Finder
A web application to search for GitHub user profiles and repositories.
## Project Description
GitHub Profile Finder is a web application that searches for
public GitHub profiles and displays popular repositories.

## Features
- Search GitHub users by username
- Display profile picture, name, and bio
- Display followers and following
- Show public repository count
- Display six repositories with the most stars
- Save recent searches in MySQL
- Handle invalid usernames and API errors

## Technologies Used
- HTML: Webpage structure
- CSS: Webpage design
- JavaScript: Search and display results
- PHP: GitHub API integration
- MySQL: Search history storage
- XAMPP: Local development server

## Installation
1. Copy the project into C:\xampp\htdocs\github-profile-finder.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin.
4. Run the commands in database.sql.
5. Open http://localhost/github-profile-finder/ in your browser.
